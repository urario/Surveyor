# Summary

The canonical requirements define a Windows GUI testability analyzer for long-lived C++/MFC/Win32 applications. Requirements are managed with `RQ-xxx` identifiers.

# Trace Rules

- Treat `docs/gui-testability-analyzer-requirements.md` as the source of truth.
- Do not rewrite requirement meaning in OKF concepts; summarize and link.
- Preserve `RQ-xxx` IDs in architecture notes, tests, implementation summaries, and reviews.
- Regenerate [rq-index.generated.md](rq-index.generated.md) when the requirement headings change.

# Key Requirement Clusters

- Problem and goals: `RQ-001` through `RQ-016`
- Evaluation criteria: `RQ-017` through `RQ-024`
- Outputs: `RQ-025` through `RQ-031`
- MVP scope and exclusions: `RQ-032` through `RQ-039`, `RQ-046`
- Success criteria: `RQ-040` through `RQ-045`, `RQ-047`
- Non-functional constraints and platform: `RQ-048` through `RQ-055`
